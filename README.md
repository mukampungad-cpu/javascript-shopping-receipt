
# JavaScript Shopping Receipt Calculator

## About the Project

This project is a shopping receipt calculator developed using JavaScript. It calculates the cost of supermarket products, applies discounts, calculates VAT, and generates a formatted receipt.

## Features

- Stores product names, prices, and quantities.
- Calculates the total price of each product.
- Calculates the subtotal.
- Applies a 10% discount when the subtotal is at least 20,000 RWF.
- Applies an additional 5% membership discount for eligible members.
- Calculates 18% VAT after discounts.
- Converts customer age and payment from strings to numbers.
- Formats the customer's name and initials.
- Calculates change or the remaining balance.
- Displays a formatted receipt and payment status.

## Technologies

- JavaScript
- Node.js
- Visual Studio Code

## How to Run

1. Install Node.js.
2. Open this project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   `node shopping-receipt.js`

5. View the receipt and calculations in the terminal.
